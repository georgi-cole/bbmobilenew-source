Visual variety includes Asian and Latine backgrounds, a person with albinism, and queer/nonbinary fictional representation. Appearance never assigns the player's identity, age, sexuality or gameplay capabilities. Read the roster's distinction between authored biography and visible traits; no identity is a purchasable attribute.

The first release customizes intact character portraits with fitted eyewear and scoped profile decoration. It does not promise interchangeable wigs, makeup, individual body garments or anatomy sliders. The rejected head/body assembly remains rejected. A complete character pack can be eligible before it has eyewear fits; compatibility is explicit before payment.
