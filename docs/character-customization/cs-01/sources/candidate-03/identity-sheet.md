The game's Nova avatar and Ali grey-lux portrait were inspected only to set the separate background treatments.

Main and grey reuse the same frozen portrait-person foreground. Main uses a near-black scene with subtle, scattered gold particles and short lines near the perimeter, following the actual game-avatar gold treatment. Grey keeps the person in natural color on a softly lit grey field whose outer tones visibly darken toward the edges, following the Ali grey-lux reference. Sad uses the main background treatment. The transparent foreground and generated sad-state output are retained under `sources/` and listed by hash in `evidence/export-report.json`.

If visually accepted, keep this portrait source and identity sheet as the portrait lineage reference for later pack production. The remaining five scene roles still need their own authored work and acceptance; do not count this pilot as a finished pack.
