# Replacement ceremony family (#1707)

## Outcome ownership

The opening block is observed by a store-scoped middleware before Safety resolves.
The selector compares that block with committed nominees. No movie receives a
proposed selection. Human VIP picks commit first; Standard keeps its existing
native deferred callback. AI and Confessional use the same committed descriptor.
The existing season-persisted replacement receipt owns completion and replay
suppression. The renderer has no gameplay dispatches.

The middleware observes after the existing presentation and Ambush normalization

from the resolved plan; the generic renderer is never given an executed Ambush.
No second global presentation queue was introduced.

## Storyboard implemented by the reusable chamber

- Establish: continuing nominee(s) on occupied platforms; incoming positions dim.
- Authority: actual chooser in the existing decision-back pose, restrained gold light.
- Reveal: incoming character(s) enter sequentially, grounded above the platform surface.
- Resolve: all final nominees remain visible; names sit below their feet and the short
  result sentence is in the lower safe area. Vox uses its existing broadcast set,
  without platforms or a player presented as chooser.
- Handoff: the existing bridge unloads scene resources and runs the compact native
  badge confirmation. Artwork failure uses the full native fallback. Skip and
  visibility/ownership remain controlled by the existing bridge.

Detox and Double Trouble use compact native save receipts instead of additional
full save films before their combined replacement film. Single initial nominations
use the original nomination scene with one visible, centered platform; no second
character is invented.

## Validation scope

Outcome tests cover authority, intermediate picks, Ambush precedence, concealed
information, pair completeness, stable identities, missing targets, new games,
Confessional-like remounts and restoration. Film tests cover every family variant,
selector validity, text safety, and animation bounds. These tests do not substitute
for device visual review or full in-game manual walkthroughs of every power.
